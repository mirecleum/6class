📖 1. Основные понятия


Координатная плоскость — что это?

Две числовые оси, пересекающиеся под прямым углом в точке O (начало координат), образуют координатную плоскость.

Оси координат:

  • Ось Ox (абсцисс) — горизонтальная ось. Вправо — положительные числа, влево — отрицательные.
  • Ось Oy (ординат) — вертикальная ось. Вверх — положительные числа, вниз — отрицательные.
  • Начало координат O(0; 0) — точка пересечения осей.

Координаты точки:

Каждая точка плоскости задаётся парой чисел (x; y), где:

  • x — абсцисса (первая координата) — расстояние от оси Oy (отсчитывается горизонтально)
  • y — ордината (вторая координата) — расстояние от оси Ox (отсчитывается вертикально)

Пример: точка A(3; −2) — отложить 3 вправо, 2 вниз.

Как запомнить порядок координат?
«Иди сначала направо (или налево), потом вверх (или вниз)»
То есть сначала x (горизонталь), потом y (вертикаль).

Запомни: «ПО улице, затем В дом»
(горизонталь → вертикаль = x → y)

📖 2. Координатная плоскость (схема)


Четыре квадранта координатной плоскости:

I квадрант

x > 0, y > 0

(правый верхний)

Пример: A(2; 3)

II квадрант

x < 0, y > 0

(левый верхний)

Пример: B(−3; 1)

III квадрант

x < 0, y < 0

(левый нижний)

Пример: C(−2; −3)

IV квадрант

x > 0, y < 0

(правый нижний)

Пример: D(3; −2)


Точки на осях:

  • Если точка на оси Ox → у неё y = 0. Например: M(5; 0)
  • Если точка на оси Oy → у неё x = 0. Например: N(0; −3)
  • Если точка в начале координат → O(0; 0)

📖 3. Алгоритмы работы с точками

📌 Как построить точку по координатам A(x; y):
  1. От начала координат O отложи по оси Ox значение x (вправо если «+», влево если «−»)
  2. Из полученной точки восстанови перпендикуляр к оси Ox
  3. Отложи по оси Oy значение y (вверх если «+», вниз если «−»)
  4. Поставь точку и подпиши её
📌 Как определить координаты точки по чертежу:
  1. Из точки опусти перпендикуляр на ось Ox → прочитай значение x (абсциссу)
  2. Из точки опусти перпендикуляр на ось Oy → прочитай значение y (ординату)
  3. Запиши координаты в скобках через точку с запятой: (x; y)

Не путай x и y местами! Всегда сначала АБСЦИССА (x), потом ОРДИНАТА (y).

Точка A(3; 5) и точка B(5; 3) — это РАЗНЫЕ точки!

Пример определения квадранта без чертежа:

Точка M(−5; 3): x = −5 (отрицательное), y = 3 (положительное) → x<0, y>0 → II квадрант
Точка K(7; −1): x = 7 (положительное), y = −1 (отрицательное) → x>0, y<0 → IV квадрант
Точка P(−4; −6): x = −4 (отрицательное), y = −6 (отрицательное) → x<0, y<0 → III квадрант
Точка Q(2; 0): y = 0 → точка лежит на оси Ox

📖 4. Расстояние на координатной плоскости


Расстояние между двумя точками на одной горизонтали (одинаковый y):

|AB| = |x₂ − x₁|

Расстояние между двумя точками на одной вертикали (одинаковый x):

|AB| = |y₂ − y₁|

В общем случае (теорема Пифагора, для 6 класса достаточно знать для осей):

Если точки на одной прямой, параллельной оси — считаем разность координат по модулю.

Пример:
A(−2; 3) и B(4; 3) — у обеих точек y = 3, значит они на одной горизонтали.
|AB| = |4 − (−2)| = |4 + 2| = |6| = 6 единиц

C(1; −3) и D(1; 5) — у обеих точек x = 1, значит они на одной вертикали.
|CD| = |5 − (−3)| = |5 + 3| = |8| = 8 единиц

📖 5. Уравнение — основные понятия


Определение

Уравнение — это равенство, содержащее неизвестное (переменную), значение которой нужно найти.

Корень уравнения — значение переменной, при котором уравнение становится верным равенством.

Решить уравнение — найти все его корни или доказать, что корней нет.

Основные свойства равенства (правила переноса):

🔑 Главные правила решения уравнений:
  • Правило 1: Если перенести слагаемое из одной части уравнения в другую, его знак меняется на противоположный.
    x + 5 = 12 → x = 12 − 5
  • Правило 2: Обе части уравнения можно умножить или разделить на одно и то же ненулевое число.
    3x = 15 → x = 15 : 3 = 5
  • Правило 3: Если слагаемое переходит через знак «=», оно меняет знак.
    Слагаемое «+» становится «−», и наоборот.
Главная цель при решении уравнения:
Получить вид «x = (число)»
Для этого нужно собрать все x в одну сторону,
а все числа — в другую сторону!

📖 6. Типы уравнений и алгоритмы решения

🔷 Тип 1: Простейшие уравнения


Вид: x + a = b или x − a = b или a · x = b или x : a = b


Используем правила нахождения неизвестного компонента:

  • Неизвестное слагаемое = сумма − известное слагаемое
  • Неизвестное уменьшаемое = разность + вычитаемое
  • Неизвестное вычитаемое = уменьшаемое − разность
  • Неизвестный множитель = произведение : известный множитель
  • Неизвестное делимое = частное × делитель
  • Неизвестный делитель = делимое : частное
Примеры простейших уравнений:

x + 13 = 28
x = 28 − 13 = 15. Проверка: 15 + 13 = 28 ✓

x − 7 = −3
x = −3 + 7 = 4. Проверка: 4 − 7 = −3 ✓

4x = 36
x = 36 : 4 = 9. Проверка: 4 · 9 = 36 ✓

x : 6 = −5
x = −5 · 6 = −30. Проверка: −30 : 6 = −5 ✓

🔷 Тип 2: Уравнения с переносом слагаемых


Вид: ax + b = c или ax = bx + c


Алгоритм решения:
  1. Перенести все члены с x в левую часть, числа — в правую
    (при переносе знак меняется!)
  2. Привести подобные слагаемые
  3. Разделить обе части на коэффициент при x
  4. Сделать проверку
Подробный разбор: 5x − 8 = 2x + 10

1
5x − 8 = 2x + 10
Переносим 2x влево (меняем знак: +2x → −2x), −8 вправо (меняем знак: −8 → +8)
2
5x − 2x = 10 + 8
Приводим подобные слагаемые
3
3x = 18
Делим обе части на 3
4
x = 18 : 3 = 6
Получили ответ
✓
Проверка: 5·6 − 8 = 30 − 8 = 22; 2·6 + 10 = 12 + 10 = 22. ✓
Ответ: x = 6

🔷 Тип 3: Уравнения со скобками


Алгоритм решения:
  1. Раскрыть скобки (умножить каждый член в скобках на множитель перед скобкой)
  2. Перенести x в одну сторону, числа — в другую
  3. Привести подобные слагаемые
  4. Разделить на коэффициент при x
  5. Сделать проверку

Правила раскрытия скобок:

  • +(a + b) = a + b — знаки не меняются
  • −(a + b) = −a − b — все знаки меняются
  • −(a − b) = −a + b — все знаки меняются
  • a(b + c) = ab + ac — каждый член умножается на a
Подробный разбор: 3(x − 4) = 2(x + 1) − 5

1
3(x − 4) = 2(x + 1) − 5
Раскрываем скобки
2
3x − 12 = 2x + 2 − 5
3·x=3x, 3·(−4)=−12; 2·x=2x, 2·1=2
3
3x − 12 = 2x − 3
Приводим подобные в правой части: 2+(-5)=-3
4
3x − 2x = −3 + 12
Переносим: 2x вправо → −2x, −12 вправо → +12
5
x = 9
✓
Проверка: Левая: 3·(9−4) = 3·5 = 15
Правая: 2·(9+1)−5 = 2·10−5 = 20−5 = 15 ✓
Ответ: x = 9

🔷 Тип 4: Уравнения с дробными коэффициентами


Алгоритм решения уравнений с дробями:
  1. Найти НОК всех знаменателей
  2. Умножить обе части уравнения на этот НОК
  3. Сократить дроби (знаменатели пропадут)
  4. Решить получившееся уравнение без дробей
  5. Проверка
Подробный разбор: x/3 + x/6 = 5

1
x/3 + x/6 = 5
НОК(3, 6) = 6. Умножаем всё на 6.
2
6 · (x/3) + 6 · (x/6) = 6 · 5
3
2x + x = 30
6/3 = 2, 6/6 = 1
4
3x = 30 → x = 10
✓
Проверка: 10/3 + 10/6 = 20/6 + 10/6 = 30/6 = 5 ✓
Ответ: x = 10

🔷 Особые случаи


Ситуация Пример Вывод
Нет корней 2x + 3 = 2x + 7 → 3 = 7 (ложь) Уравнение корней не имеет (∅)
Бесконечно много корней 3x − 6 = 3(x − 2) → 3x − 6 = 3x − 6 → 0 = 0 (истина) Уравнение верно при любом x

Задание 4. Реши уравнения (с проверкой):

  1. x + 17 = 45
  2. x − 23 = −8
  3. 6x = −54
  4. x : 4 = −12
  5. 3x + 7 = 28
  6. 5x − 14 = 2x + 7
  7. 8 − 3x = 2 + x

x = 45 − 17 = 28
Проверка: 28 + 17 = 45 ✓

2) x − 23 = −8
x = −8 + 23 = 15
Проверка: 15 − 23 = −8 ✓

3) 6x = −54
x = −54 : 6 = −9
Проверка: 6·(−9) = −54 ✓

4) x : 4 = −12
x = −12 · 4 = −48
Проверка: −48 : 4 = −12 ✓

5) 3x + 7 = 28
3x = 28 − 7
3x = 21
x = 21 : 3 = 7
Проверка: 3·7 + 7 = 21 + 7 = 28 ✓

6) 5x − 14 = 2x + 7
5x − 2x = 7 + 14
3x = 21
x = 7
Проверка: 5·7−14 = 35−14 = 21; 2·7+7 = 14+7 = 21 ✓

7) 8 − 3x = 2 + x
8 − 2 = x + 3x
6 = 4x
x = 6 : 4 = 1,5
Проверка: 8−3·1,5 = 8−4,5 = 3,5; 2+1,5 = 3,5 ✓

8) 4(x + 3) = 2(x − 1) + 18

Задание 5. Реши уравнения с дробями:

  1. x/2 + x/4 = 9
  2. x/5 − x/10 = 3
  3. (x + 2)/3 = (x − 1)/2

1) x/2 + x/4 = 9
НОК(2, 4) = 4. Умножаем на 4:
4·(x/2) + 4·(x/4) = 4·9
2x + x = 36
3x = 36
x = 12
Проверка: 12/2 + 12/4 = 6 + 3 = 9 ✓

2) x/5 − x/10 = 3
НОК(5, 10) = 10. Умножаем на 10:
10·(x/5) − 10·(x/10) = 10·3
2x − x = 30
x = 30
Проверка: 30/5 − 30/10 = 6 − 3 = 3 ✓

3) (x + 2)/3 = (x − 1)/2
НОК(3, 2) = 6. Умножаем на 6:
6·(x+2)/3 = 6·(x−1)/2
2(x + 2) = 3(x − 1)
2x + 4 = 3x − 3
4 + 3 = 3x − 2x
x = 7
Проверка: (7+2)/3 = 9/3 = 3; (7−1)/2 = 6/2 = 3 ✓


Задание 6. Составь и реши уравнение по условию задачи:

  1. В двух корзинах вместе 48 яблок. В первой в 3 раза меньше, чем во второй. Сколько яблок в каждой корзине?
  2. Задумали число. Если его умножить на 4 и прибавить 7, получится 43. Найди задуманное число.
  3. Периметр прямоугольника равен 54 см. Длина на 9 см больше ширины. Найди стороны прямоугольника.

1) Две корзины, 48 яблок, в первой в 3 раза меньше.
Пусть в первой корзине x яблок, тогда во второй — 3x яблок.
Уравнение: x + 3x = 48
4x = 48
x = 12
В первой: 12 яблок, во второй: 3·12 = 36 яблок.
Проверка: 12 + 36 = 48 ✓, 36 : 12 = 3 ✓

2) Задуманное число.
Пусть число x.
Уравнение: 4x + 7 = 43
4x = 43 − 7 = 36
x = 36 : 4 = 9
Проверка: 4·9 + 7 = 36 + 7 = 43 ✓

3) Периметр прямоугольника 54 см, длина на 9 см больше ширины.
Пусть ширина = x см, тогда длина = (x + 9) см.
Периметр: 2(x + x + 9) = 54
2(2x + 9) = 54
4x + 18 = 54
4x = 54 − 18 = 36
x = 9 (ширина)
Длина: 9 + 9 = 18 см
Ширина = 9 см, длина = 18 см.
Проверка: 2·(9 + 18) = 2·27 = 54 ✓
